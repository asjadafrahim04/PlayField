# 🏟️ PlayField

**Find. Book. Play.**

PlayField is a Playground Management & Booking System that lets users discover nearby playgrounds, check real-time availability, and book hourly slots for Football or Cricket.

## 🚧 Status

Project is under active development.

## 🧰 Tech Stack

- **Frontend:** React, Vite, Tailwind CSS, React Router, Axios
- **Backend:** Node.js, Express, JWT, bcrypt
- **Database:** MySQL
- **Tools:** VS Code, Git, GitHub, Thunder Client

- **Owner** — Manage playgrounds and bookings
- **Admin** — Approve owners, manage the platform
